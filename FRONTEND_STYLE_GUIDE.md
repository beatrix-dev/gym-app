## Design Principles

Optimise for:

- Clarity over decoration
- Information density without clutter
- Consistency over novelty
- Accessibility before aesthetics

When choosing between alternatives:

Prefer:

- fewer colours
- fewer font sizes
- more whitespace
- simpler layouts
- predictable interaction patterns

---

## Avoid

- Giant hero sections
- Excessive gradients
- Glassmorphism unless requested
- Multiple accent colours
- Decorative icons
- Visual noise

---

## Component Philosophy

Every component should define:

- Loading
- Empty
- Error
- Success
- Disabled

Every component should:

- Be reusable
- Have predictable spacing
- Follow project design tokens
- Avoid arbitrary sizing
